# EduEnrich MERN Website

Premium full-stack education consultancy website for EduEnrich.

## Quick Start

```bash
npm run install:all
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
npm run dev
```

Frontend: `http://localhost:5173`  
Backend: `http://localhost:5000`

See `SETUP.md` for complete local, email, MongoDB, deployment, and domain setup.
